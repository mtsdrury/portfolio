The Problem

Fashion brands and designers need a way to quantify subjective aesthetic concepts like "90s minimalism" or "dark academia" for search, recommendation, and trend analysis. Existing fashion datasets focus on structural attributes (garment type, color) but lack the vocabulary to describe vibes, eras, and aesthetic movements that actually drive style decisions.

What Was Built

The system combines four complementary data sources to train a multi-label classification model. DeepFashion2 provides 491K annotated images for structural grounding (garment categories, landmarks, shapes). A synthetic dataset generated through OpenArt allows perfect label control for rare aesthetic combinations, encoding specific brand taste without manual annotation. Flickr Creative Commons photos contribute real-world diversity with community-generated tags, filtered by license and weighted by tag specificity. Are.na channels surface high-signal curated references from designers, with connection count serving as a quality signal. The data collection pipeline includes three purpose-built scripts: a prompt generator that creates structured OpenArt queries mapped to known labels, a Flickr collector that filters by Creative Commons license and tag relevance, and an Are.na scraper that discovers and harvests from fashion-focused channels. A custom taxonomy in YAML defines the aesthetic vocabulary (vibes, eras, attributes) that the model learns to recognize. The architecture treats this as a multi-label problem where images can embody multiple aesthetics simultaneously, reflecting how real fashion operates.

Outcome

The repository provides a complete data collection infrastructure with 1,911 lines of pipeline code across three specialized collectors. The modular design allows brands to customize their aesthetic taxonomy and generate training data that reflects their specific vision. Currently in the data collection phase, with the training architecture documented and ready for implementation.

Highlights

Synthetic Data with Perfect Labels

The OpenArt prompt generator creates structured queries where each generated image maps to known aesthetic labels, eliminating annotation costs. This approach enables training on rare combinations and edge cases that may not exist in real-world datasets, while encoding specific brand taste rather than generic fashion understanding.

Multi-Source Quality Signals

Each data source contributes a distinct signal: DeepFashion2 for structural accuracy, synthetic data for aesthetic precision, Flickr tags for real-world diversity, and Are.na connection counts for curatorial quality. The pipeline weights samples by these intrinsic quality indicators rather than treating all data equally.

Customizable Aesthetic Taxonomy

The YAML-based taxonomy allows brands to define their own aesthetic vocabulary rather than using fixed categories. This flexibility means the same pipeline can train models for streetwear, haute couture, or vintage fashion by simply editing label definitions.
