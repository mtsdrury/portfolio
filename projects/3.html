Aura Index

Multi-source ML pipeline for indexing fashion aesthetics and vibes

The Problem

Fashion search and recommendation systems struggle to capture subjective qualities like vibes, eras, and aesthetics. Most models only understand categories and shapes, not the feeling or style that makes fashion resonate with people.

What Was Built

The system combines four data sources to train a model that understands both structure and style.

  • DeepFashion2 provides structural grounding with 491K annotated images covering categories, shapes, and landmarks
  • OpenArt synthetic generations encode specific aesthetics by generating images from controlled prompts mapped to known labels
  • Flickr Creative Commons images add real-world variety with community tags, filtered by tag specificity as a quality signal
  • Are.na channels capture high-signal curation from designers, weighted by connection count across boards

The taxonomy.yaml file defines custom aesthetics, eras, and attributes that matter for the specific use case. The generate_prompts.py script creates structured prompts where each generated image maps cleanly to labels, eliminating annotation work. Data collectors in collect_flickr.py and collect_arena.py handle API pagination, license filtering, and metadata extraction. Each source contributes different knowledge: DeepFashion teaches what clothes are, OpenArt teaches what vibes feel like, Flickr adds diversity, and Are.na adds taste.

Outcome

The repository provides a complete data collection pipeline ready for model training. Three collection scripts handle multi-source ingestion with quality filtering, and the prompt generator enables controlled synthetic data creation. The modular structure allows adding new data sources or adjusting the taxonomy without changing collection logic.

Highlights

Controlled synthetic data generation

The generate_prompts.py script creates prompts where each image maps to known aesthetic and era labels. This eliminates manual annotation and lets the model learn specific vibes by encoding them directly into training data. The approach trades off naturalistic distribution for perfect label quality.

Quality-weighted multi-source learning

Each data source receives quality signals. Flickr images weight by tag specificity, treating more detailed tags as higher confidence signals. Are.na blocks weight by connection count across channels, using curation frequency as a proxy for resonance. This lets the model learn which signals to trust.

Taxonomy-driven collection

The taxonomy.yaml configuration drives data collection across all sources. Flickr queries use taxonomy terms as search tags, generating prompts combines taxonomy labels, and Are.na discovery filters by aesthetic keywords. This ensures collected data aligns with the target use case.

License-aware data pipeline

The collect_flickr.py script filters by Creative Commons licenses and the Are.na collector uses the open API. DeepFashion2 comes with academic use permission. This makes the entire dataset legally usable for training without rights concerns.
