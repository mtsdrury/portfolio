The Problem

Developers need portfolio sites to show their work, but writing descriptions takes time and most repos lack documentation. Manually creating portfolio pages from scratch requires design skills and ongoing maintenance. This tool automates the entire process from code analysis to published site.

What Was Built

  • Users authenticate via GitHub OAuth and select repositories to analyze
  • The system clones each repo and examines file structure, detects technologies, and samples representative code
  • A pipeline (pipeline.py) sends structured data to Claude API with custom prompts that extract project purpose, technical approach, and key features
  • Analysis results are stored as JSON in SQLite and mapped to portfolio items with customizable visibility and ordering
  • Portfolio sites render from templates with selectable themes (themes.py provides CSS variables for colors, fonts, layout)
  • Users can edit generated content, upload avatars, add social links, and apply custom CSS
  • Published portfolios are accessible via unique slugs with SEO metadata and Open Graph tags
  • Pro tier unlocks deep analysis mode, custom domains via GitHub Pages push (github_push.py), and unlimited projects

Outcome

A working SaaS platform that handles the full pipeline from repository to live portfolio site. Users can generate, customize, and publish portfolios without writing HTML or design work. The system is deployed on Fly.io with Stripe integration for subscriptions.

Highlights

Smart code sampling strategy

file_sampler.py uses a token budget system to include representative files from each directory. Prioritizes main entry points, configuration files, and distributes remaining budget proportionally across subdirectories. This keeps Claude API requests under token limits while capturing project structure.

Ownership detection

ownership.py clones repos and runs git log to count commits by author email. Calculates contribution percentage and classifies users as owner, collaborator, or contributor. Helps filter out minor contributions and surfaces repos where the user had significant involvement.

Flexible theming system

Built with CSS custom properties that users can override. THEMES dictionary in themes.py defines presets for color schemes, typography, and layout. Pro users can inject custom CSS while free tier gets curated themes. Templates inherit from site_base.html with blocks for easy extension.

Static export and GitHub Pages deployment

static_export.py renders portfolio HTML with embedded assets and pushes to a GitHub repo via PyGithub. Enables custom domain hosting without depending on the main app. Users get a standalone site they control fully.
