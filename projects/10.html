Job Tracker

A job search tracker with CSV backend and modern GUI

View Repository →
Python tkinter CSV PyInstaller

The Problem

Job seekers need to track applications, referrals, and follow-ups without the overhead of databases or cloud accounts. Spreadsheets work but quickly become unwieldy as applications pile up and referral outreach gets lost in rows. A lightweight tool that keeps everything in one CSV file while providing structured views and automated action items solves this.

What Was Built

  • The system stores all job data in a single CSV with 15 columns covering company, role, status, referrals, cover letters, and notes
  • A CLI (tracker.py) provides commands for adding jobs, updating fields, filtering, and generating summary reports with visual charts
  • The GUI (gui.py) uses a mixin architecture where TrackerApp composes functionality from ListTabMixin, DetailTabMixin, ActionsMixin, and others
  • Five tabs organize views: a filterable job list, a detail editor, an actions panel that flags stale applications and un-messaged referrals, an analytics dashboard, and a chat interface
  • Referral management supports multiple contacts per job with separate fields for LinkedIn URLs, connection notes, and outreach status, all stored in semicolon-delimited strings
  • The detail tab uses a scrollable canvas to display all 15 fields as entry widgets, with a file browser for cover letters and inline referral management
  • Auto-fill extracts company, role, and location from pasted job URLs by parsing schema.org JSON-LD when available
  • PyInstaller packages the app into a standalone .exe with no Python installation required, using a custom spec file in src/packaging/

Outcome

The tool runs as either a CLI or GUI, with a distributable Windows executable that creates a blank CSV on first launch. The GUI handles filtering by status and referral state, auto-detects incomplete fields, and generates weekly reports with action items. The architecture keeps all logic in pure Python with zero external dependencies beyond ttkbootstrap for theming.

Highlights

Mixin-based GUI composition

TrackerApp inherits from eight mixin classes (ListTabMixin, DetailTabMixin, ActionsMixin, etc.) to separate concerns. Each mixin owns a single tab's logic and widgets. This keeps app.py under 200 lines while supporting five distinct views with shared state.

Referral pipeline tracking

Each job stores multiple referrals as semicolon-delimited strings across four CSV columns: names, LinkedIn URLs, connections, and statuses. The GUI provides a popup form to add referrals and tracks outreach progression (Has Referral, Messaged, Submitted). The actions tab flags jobs with referrals that have not been contacted yet.

Automated action items

The CLI report command and GUI actions tab analyze the CSV to surface stale applications (21+ days in Applied status), un-messaged referrals, and large Not Yet Applied backlogs. Each action item links to the relevant job. This turns passive data into a prioritized task list.

Schema.org URL parsing

The New Job popup parses pasted URLs to extract company, role, and location from schema.org JSON-LD metadata embedded in job postings. Falls back to basic HTML parsing when structured data is unavailable. Reduces manual entry for each new application.
